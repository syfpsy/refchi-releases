# refchi

**A calm, local-first creative asset manager for designers and visual thinkers.**

Collect images, fonts, colors, bookmarks, and references in one place. Browse fast, find anything, stay inspired. All your files stay on your machine — no cloud, no account, no subscription.

> **Website:** [refchi.com](https://refchi.com) · **Release notes:** [refchi.com/landing/releases](https://refchi.com/landing/releases)
